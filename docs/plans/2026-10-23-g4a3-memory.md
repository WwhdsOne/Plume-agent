# G4a.3 长期记忆立项与分单元实施计划

用户于 2026-10-23 授权无人值守完成立项和首个可运行子单元；执行跨至 2026-10-24，保留指定文件名，以 updated 记录实际日期。G4a.1、G4a.2 已通过，不重做。本文授权实施范围仅 G4a.3.1，交付 pending-review 后停止；其余单元是计划，必须另行授权。

使用 writing-plans 的设计自查与测试先行步骤，在当前工作区顺序执行；用户明确要求无人值守、一条提交及只改当前仓库，因此不插入计划审批、不另建 worktree、不提前提交设计。状态依据 [审核记录](../reviews/G4a.3.1.md)。

## 目标、非目标与取舍

目标是将用户明确指定的事实、偏好保存为可核对来源、可更新、有作用域的长期记录，最终按当前任务选择相关条目，在 run preparing 固定快照后交给 PromptBuilder。历史轮次、人格和记忆分别保留各自职责。

明确不做 MCP、skill、自动压缩、跨设备同步、向量库、embedding、模型自动提取、后台整理、工具自动重试或跨进程并发所有权。本期没有 token 估算器，不宣称 token 硬预算或模型容量保障。不从聊天全文、工具结果、soul.md 或凭据文件自动生成记忆。

比较三种存储：独立 Markdown 容易编辑但难以原子更新和隔离；独立数据库会重复锁、权限、退出治理；现有私密 history.db 新增专表能够复用 SQLite 事务及权限。选择第三种，复用已锁定 modernc.org/sqlite v1.60.1，不新增依赖。账本先交付，公共管理入口、任务召回分开审核，以免首次上线就改变所有模型请求。

## 职责与数据流

| 模块 | 职责与边界 |
| --- | --- |
| internal/store | 记忆持久化、作用域验证、并发更新、读取上界；SQLite 与内存后端同契约。不决定任务相关性、不拼 prompt。 |
| internal/app（G4a.3.2 起） | 从可信入口固定 owner、规范工作区与会话身份；显式管理指令、收据重放与结果展示。不接受正文指定身份绕过权限。 |
| internal/memory（G4a.3.3 才创建） | 有真实消费者后实现纯确定性候选选择、来源标记、总量预检；不另存数据库、不解析人格、不授予工具许可。 |
| internal/agent | G4a.3.3 由 run preparing 获取一次记忆快照；PromptBuilder 接已准备上下文并核验完整请求预算。Generate/Stream 及工具续调共用快照。 |
| internal/soul | 继续只初始化/读取配置目录人格，记忆不写入 soul.md。 |

G4a.3.1 的数据流是演示程序/契约调用 → LongTermMemoryStore → SQLite → 关闭重开 → 同域有界读取。现有聊天没有账本消费者，memory 文本槽继续为空；不添加未消费的配置、运行时接口或新包。LongTermMemoryStore 的两个方法立即由双后端契约测试和演示消费，不修改既有 Store 故障装饰器。

## 数据模型与语义

表 memory_entries 的身份是复合主键 `(scope_key, scope_type, workspace, session_id, memory_key)`，没有全库裸内容哈希，也不以猜测相似度去重。

| 字段 | 定义 |
| --- | --- |
| scope_key | 非空可信权限主体，例如 local、某渠道账号；所有作用域都受此字段隔离。global 表示本主体跨工作区，并非所有用户共享。 |
| scope_type | global / workspace / session，不能省略。 |
| workspace | global 必须为空，其余必须是入口已规范的绝对路径；账本检查绝对、clean 格式，不替调用方解析符号链接。 |
| session_id | 只有 session 类型非空；必须存在于同主体和工作区的会话元数据，不能抢占他人的 ID。 |
| memory_key | 用户/管理入口选择的稳定键，区分大小写，精确去重；不做隐式 trim、大小写或语义合并。 |
| content | 非空白 UTF-8 正文；只进入私密历史库及授权的调用结果。 |
| source | 首单元仅接受 user，表示调用方显式提交；没有自动学习。未来增加自动来源须同时实现来源证明与单独审核迁移。 |
| revision | 从 1 开始的整型版本，compare-and-swap 更新，不以最后写入覆盖冲突。 |
| created_at / updated_at | 存储层生成的 UTC 毫秒时间；创建时间不变，更新时不倒退；相同内容重放不更新时间。 |

PutMemory 的 expected_revision=0 为只创建；大于 0 为基于已读版本更新。同身份、同内容和来源的首次重投（当前 revision=expected+1）返回首次结果；当前版本上的相同内容也是空操作。其他陈旧版本返回 ErrMemoryConflict，不改变原值。不同键可保存相同内容，因为语义身份由明确键决定。创建/修改单条原子提交，错误不携带正文、键、原始驱动报错或内容裸哈希；取消保留标准 context 错误身份。IO/提交错误不能证明一定未提交，调用方必须重新按同域读取核对，禁止盲目覆盖。

本单元不提供删除，防止没有操作收据时旧 create 重投复活已遗忘内容。G4a.3.2 将管理操作收据和删除同事务实现，收据仅保留操作 ID、目标身份及结果版本，不复制正文；若需要请求指纹，采用进程外持久私密密钥的 HMAC 或不存正文的随机操作版本，不落可猜测内容裸哈希。届时明确删除后历史库备份仍可能有副本，SQLite 删除不承诺安全擦除。

## 迁移、兼容与回滚

SQLite user_version 从 2 升至 3，与 config schema v1 分离。memory_entries 专表及查询索引、scope CHECK 约束与版本发布同一事务；v0/v1 先执行原迁移再升到 v3，旧 sessions/runs/turns/model_calls/bindings/command_receipts 均不重写。DDL 中途失败回滚所有新增表/索引及版本，原数据可继续由旧版读取；版本大于 3 继续拒绝，不删库重建。

复用整库独占锁、0600 数据库/辅助/锁文件、0700 新目录与现有 Unix 限制。已存在的父目录权限保持原约定。不访问真实 ~/.plume；测试与演示只用临时目录。即使未使用记忆，打开历史库也会迁移到 v3，必须在审核说明这一兼容影响。

回滚程序不自动降级数据库：停所有持库进程后备份整库及相关文件，升级前的 v2 备份才能供旧二进制使用；v3 被旧程序拒绝是预期保护。开发回滚只撤销本单元变更或删除隔离演示库，不删除用户库，不 git reset --hard、不丢弃他人文件。

## 无 token 估算器时的预算与召回

G4a.3.1 ListMemories 只读取**一个精确作用域**，按 memory_key 二进制升序返回完整集合，不声称是语义召回。单条所有文本字段 UTF-8 字节之和加三个 int64（24 字节）最多 8192；单次默认/硬上限 100 条、65536 字节，可通过 MemoryLimits 指定更小正上限，负值或放宽硬上限明确拒绝；零值使用默认。

SQLite 先在同一读事务中 COUNT/SUM(CAST(... AS BLOB)) 计量，再读正文；内存后端在同锁下计量。超过条数或字节返回 ErrMemoryLimit 和 nil 结果，不返回前 N 条、不截断单条、不忽略超限条目。键、owner 和路径也计量；无 token 推测。输入超限、非法 UTF-8、非法来源及身份在写入前拒绝。损坏磁盘记录在返回前验证，统一拒绝，不将残片送入请求。

G4a.3.3 计划：先按可信主体筛 global、当前 workspace、当前 session 的候选，每个范围仍受账本边界约束；不扫描其他身份。采用用户明确键优先，其次当前输入与键/正文的确定性词面匹配，固定排序、来源和原因；无匹配不添加空标题。候选全集超限须明确要求缩小键/范围或整理账本，不能先截断再声称完整召回。选中集合最多 16 条、16384 UTF-8 字节（含来源包装）；超限在首次模型前失败，不自动省略。完整 ChatRequest 再用 agent.budget.request_bytes 检查，JSON 转义膨胀也计入。条数/字节均不是 token；供应商 usage 缺失继续 unknown。

记忆始终是参考数据，不覆盖基础规则/用户指令、不改变 tools.enabled，不授予执行权限；来源区块中的指令也不改变代码权限。trace 只记条数、字节、作用域类别、结果码，不记正文、记忆键、凭据、来源原文或独立内容哈希。

## 风险与验收口径

记忆可能含个人信息：只存私密库，不写日志/trace；演示用合成正文、临时库销毁，保留脱敏 trace。凭据不属于记忆接口的输入来源，不读凭据、不把 Key 自动提取为记忆；本期不具备识别任意用户文本中秘密的能力。

作用域依赖可信入口传入规范工作区，存储不是 OS 身份认证边界；全球共享必须同一主体明确写 global。会话作用域要求元数据已存在，默认未落盘空会话不得偷偷创建孤儿记忆。没有后台 TTL、语义冲突合并、加密或磁盘安全擦除。失败不保证回滚已确认提交的更新；提交确认不明须读取核对。

基线只报实际测试结果、演示步骤通过率、模型调用数及迁移结果；延迟分位数、token、费用、质量收益未测记 N/A，变化列 N/A。路线图只改 ROADMAP 数据和元数据，浏览器打开验证；若环境不可用如实记录限制。
