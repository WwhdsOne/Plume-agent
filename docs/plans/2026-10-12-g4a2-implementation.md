# G4a.2 公共指令与历史交互实施计划

依据 [历史会话与统一指令方案](2026-10-10-session-history-commands.md)；用户于 2026-10-12 授权实施。G4a.1 与全部修复已提交 `97568ec` 并推送 `origin/main`。本单元在 `codex/g4a2-commands` 实现，于 2026-10-23 完成验证并获用户提交、继续授权；本文仅记录已完成步骤，实际结果见审核记录。

## 目标与边界

公共指令先于模型准入，TUI 与可信渠道适配复用应用层处理器。首批提供 `/help`、`/new`、`/sessions`、`/resume`、`/rename`、`/history`、`/status`、只读 `/model`、`/cancel`（`/stop`）；TUI 增加 `/clear`、`/exit`（`/quit`）。`//` 转义为普通消息，前缀只用于建议，Enter 不执行候选首项。

不接真实 gateway，不实现模型迁移、压缩、记忆、MCP 或 skills 加载器。补全以候选来源接口保留后续扩展边界。沿用现有配置 `sessions.page_size`，不新增无消费者字段或依赖。

## 实施顺序

- [x] 存储首版：迁移 v1 → v2；会话作用域、手工标题、分页查询；绑定与命令收据同事务；内存与 SQLite 同契约。默认无 run 空会话只驻内存，手工命名后落盘；目录不列默认空会话。
- [x] 纯命令层首版：目录、严格解析、结构化结果、身份作用域和可扩展补全来源；失败不调用模型。
- [x] 应用处理器首版：标题生成、当前绑定、新建/恢复/重命名、只读查询、固定目标取消；准入锁与保存不确定性共同保护；事件携带会话 ID。
- [x] CLI 装配首版：启动配置快照与当前凭据重建恢复运行时；禁用历史/offline 使用内存后端；`-c` 仍限本地工作区有 run 历史。
- [x] TUI 首版：异步 Hooks 命令、上下与 Tab 补全、Esc 与 Ctrl+C 优先级、可预览选择器、历史分页；失败保留草稿和转录，成功再替换统计与显示。
- [x] fake gateway 测试：跨用户/渠道/线程隔离、命令收据重放、空闲及旧目标取消、发送失败重送；不宣称真实平台 exactly-once。
- [x] 独立规格与质量复审，修复发现；全量竞态、vet、lint、格式及 build.sh；本地 fixture 的 PTY 成功/失败证据。
- [x] 交付 `docs/reviews/G4a.2.md`，同步契约、AGENTS、索引、路线图和当日日志；2026-10-23 用户授权提交并继续。

## 验收

1. 指令、解析错误、权限失败、预览和切换均无模型调用；完整普通文本保持现有工具循环行为。
2. 权限域过滤先于 ID 前缀解析；不可见与不存在均 `session_not_found`；同域重复 RequestID 复用原结果，内容变化拒绝。
3. 绑定/重命名/收据原子提交后才更新内存；恢复装配或保存失败保持原会话。取消收据固定首次 run，重复消息不取消后来任务。
4. 展示分页且净化，恢复成功上下文完整校验；新会话使用本次实际启动选定模型（裸启动 default_model、显式 `--model` 引用、`-c` 启动恢复引用），后续 `/resume` 不改变此基准；恢复使用历史兼容模型，工具许可采用当前配置快照、读取证明不恢复。
5. SQLite v1 数据保留、未来版本拒绝、迁移失败无半状态；关闭历史不创建数据库。
6. `rtk go test -race ./...`、`rtk go vet ./...`、`rtk proxy go tool golangci-lint run`、`rtk proxy gofmt -l cmd internal`、`rtk proxy ./scripts/build.sh` 通过。指标仅报实际样本与绝对值，变化 N/A。

当前行为见 [公共指令契约](../specs/session-commands.md)，正式验证见 [G4a.2 审核记录](../reviews/G4a.2.md)。本计划已完成，后续具体单元需先明确范围。
