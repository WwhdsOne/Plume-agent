# TUI 开屏与主题色（G1b.2.2）

- 日期：2026-10-07。触发：G1b.2.1 审核通过后，用户指定下一步先做开屏画面（参照 Hermes Agent / Claude Code 的 TUI 开屏），并拍板主题三色。高优先级，插队 G1b.3 之前。
- 参照：Hermes Agent 开屏（ASCII 大标题 + 版本行 + 信息区 + 底部提示）。plume 首版没有工具/技能系统，**开屏只展示真实存在的信息**，不伪造清单。

## 1. 主题色（雾青）

| Token | 值 | 语义 | 应用 |
| --- | --- | --- | --- |
| `themePrimary` | `#5BC8C8` / hsl(180,45%,57%) | 主色 | 开屏标题 art、助手角色标记 `●`（G1b.3） |
| `themeLight` | `#7DD3D8` / hsl(184,47%,67%) | 浅色态（次要） | 开屏版本/模型信息行 |
| `themeDark` | `#3A9EA3` / hsl(183,47%,43%) | 深色态（强调） | 用户角色标记 `>`（G1b.3）、状态栏 running 态 |

- 语义色不占用主题色：错误红（`9`）、一次性提示黄（`11`）、中性暗灰（`8`）保留。
- 色值集中在 `internal/tui/theme.go`，其余文件不得出现裸色值。

2026-10-08 补充：角色符号替换及 `Thought` 三点三角旋转动画已按 [G1b.3 契约](tui-streaming.md) 实现，并随 G1b.3 审核通过；G1b.2.2 历史证据保留原样。
- hex 真彩色由 lipgloss v2 按 `COLORTERM`/终端能力自动降级（256 色/16 色/无色），无需手写降级分支。

## 2. 开屏内容（2026-10-07：用户指定盲文点阵羽毛）

宽度 ≥ 80 列（`splashBoxMinWidth`）时渲染：

- **方框上方**：`PLUME-AGENT` **立体像素字**（6 行，`█` 实心笔画配 `╔╗╚╝═║` 双线阴影；主体主青、阴影深青，沿用左对齐）。2026-10-09 按用户 HERMES-AGENT 参考图改为该字形：窗口至少 94 列使用 94 列完整版，80–93 列使用 71 列紧凑版，同样保留轮廓层次与完整标题。
- **圆角方框**（雾青主色描边，宽 min(终端-2, 88)，**四条边完整、顶边不嵌任何文字**）：
  - **左栏**：从用户羽毛参考图等比例采样的 **64×80 点位**，每 **2×4 点位**编码为一个 Unicode 盲文字符（`U+2800`–`U+28FF`），显示为 **32 列 × 20 行**。保留主羽叶与右羽叶之间的斜向负空间、右上分离碎羽与左下细茎。三色沿对角线过渡：右上深青 → 中段主青 → 左下浅青；同一字符的点共用前景色，不填背景。左栏两侧各留白 2 列。字符矩阵保存在 `featherBraille`，运行时不加载图片。
  - **分隔竖线**：LOGO 与右栏之间一根主色 `│`，贯穿框内全高。
  - **右栏**：
    1. 版本行 `plume-agent v<version> (<commit>)`（浅色）
    2. 标题行 `Tips for getting started`（浅色）
    3. 键位提示 9 行，快捷键浅青、说明暗灰，说明列统一对齐：Enter/Esc、Shift+Enter、Alt/Option+Enter、`\`+Enter 兜底、Up/Down、PgUp/PgDn、Ctrl+L/Ctrl+N、Ctrl+C 双击、Ctrl+D。Alt/Option 名称取自 KeyMap 的平台帮助文本；两种退出提示注明空输入条件。
    4. 分隔线（暗灰）
    5. 模型标签（浅色）
    6. 工作目录（暗灰，超宽截断）；版本/模型/路径均先净化为单行纯文本，再按终端列宽裁剪并补齐，中文路径不撑破边框。

32 ≤ 宽度 < 80 列降级：无大标题无方框，点阵羽毛 + 信息行（版本·标签）+ 键位提示竖排，信息和提示按可见列宽折行。宽度 < 32 列时使用小标题 `PLUME` 与折行文本。

不展示：工具/技能清单（G3 之前不存在）、会话 ID（无此概念）。

## 3. 行为规则

- 开屏是**聊天记录区的初始内容**（随记录滚动，不是独立覆盖层/欢迎页）：实现最稳，不引入新布局状态，PgUp 可以回看。
- 开屏只出现一次：启动渲染；`Ctrl+N` 新会话清空记录后**不**重新渲染（沿用 "New session started" 提示行）。
- 像素字行与方框行**不参与折行**（折行即毁）；首次拿到正数宽、高时一次性渲染；颜色能力、环境快照、时钟等先到的启动消息不得消耗开屏，窗口变化不重排。
- 像素字行、方框行含多种颜色，以**已染色整行**输出（`splashRawRole`，渲染层原样直出）。
- **高度账**：宽端开屏总高 = 立体标题 6 + 方框（羽毛 20 + 上下边框 2）= **28 行**；记录区高于开屏时完整容纳，更矮终端靠滚动（2026-10-07 用户要求加大画幅）。盲文点阵不增加开屏行数。
- 版本号来自 `scripts/build.sh` 的 ldflags 注入（`main.version/commit`），未打戳时如实显示 `dev (none)`，不伪造。

## 4. 验收要点（G1b.2.2）

- `go test -race ./...` 全绿；覆盖主题色 token、开屏内容、立体字形、左对齐与完整/紧凑标题宽度、窄端降级、开屏仅渲染一次（Ctrl+N 后不复活）。长版本/模型、中文路径与控制字符输入不破坏边框，也不溢出窄终端。
- pty 演示：启动帧包含 art 行、`plume-agent v`、模型标签与键位提示；输出含非默认前景色 ANSI 序列；既有演示判据不回归。
- 真实终端人工核对三色的观感（256 色与真彩色各看一眼）；观感微调（明度/饱和）属实现细节，用户可再拍板。
- `scripts/preview_splash.py` 使用真实 pty + pyte 保存 PNG、纯文本屏幕帧、原始 ANSI 和检查结果；预览显式移除宿主的 `NO_COLOR` 等颜色覆盖变量，产品仍遵循用户终端的颜色设置。
- 预览中的盲文按捕获字符的八位点位掩码还原为圆点；真实终端的点形与点距由字体及回退字体决定。普通文字采用 SF Mono，PNG 用于核对字符布局和颜色，不承诺与所有终端字体完全一致。
