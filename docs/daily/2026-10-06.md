## 构建脚本与版本注入（同日）

用户提出：`herald version` 打的是 Go 工具链版本，装到 PATH 后无法判断二进制来自哪次构建。

新增：

- `VERSION`（仓库根，当前 `0.1.0`）——人工维护的语义版本。选它而非 git tag 驱动，因为仓库 **0 个 tag**，`git describe --tags` 直接失败。
- `cmd/herald/version.go` —— `version` / `commit` / `buildTime` 三个变量，默认 `dev` / `none` / `unknown`，由 ldflags 注入；未打戳时如实显示，不伪造版本号。
- `scripts/build.sh` —— 读 `VERSION` + `git rev-parse --short HEAD`（脏则加 `-dirty`）+ UTC 时间，注入后构建；支持 `-o/--output`、`--install`（写到 GOBIN）、`--debug`（不剥离符号）、`-h`。

实测：打戳产出 6,751,906 B（`-s -w`），裸构建 9,747,010 B；`./scripts/build.sh --install` 用临时 GOBIN 验证通过，未触碰真实 `/Users/go/bin`。

发现：`/Users/go/bin/herald` 已存在（13:25，9,746,850 B，输出旧格式 `herald-agent (go1.27.1)`），是加版本注入**之前**的裸构建产物。已提醒用户用脚本重装。
