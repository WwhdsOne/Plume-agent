# 会话历史与公共斜杠指令契约

G4a.1 持久历史与显式继续已审核通过；G4a.2 首版实现已通过独立规格复审，正在完成交付验证，尚未获用户审核通过。本文描述当前工作区的实现行为，验证结果与未完成项见 [G4a.2 审核记录](../reviews/G4a.2.md)。设计理由与后续真实渠道要求见 [历史会话与统一指令方案](../plans/2026-10-10-session-history-commands.md)。

## 指令目录与解析

TUI 和可信渠道入口共用 `internal/app` 的命令目录、纯解析器与处理器；指令先于普通消息的 busy 检查。命令、解析错误、权限错误、只读预览与会话切换均不调用模型，不进入模型上下文，也不增加成功轮次。

| 指令 | 当前行为 | run 运行时 |
| --- | --- | --- |
| `/help [command]` 或 `/` | 显示当前入口支持的命令；帮助目标可带一个 `/` | 可用 |
| `/new [title]` | 新建随机 ID、空上下文并切换，旧会话保留 | 拒绝，提示先取消 |
| `/sessions [page]` | 当前权限域、工作区的会话目录 | 可用 |
| `/resume [id]` | TUI 无参数打开选择器；可信渠道无参数返回目录和用法；有 ID 时恢复目标 | 拒绝，提示先取消 |
| `/rename <title>` | 手工命名当前会话 | 拒绝，提示先取消 |
| `/history [page] [--session <id>]` | 只读查看当前或指定可见会话的已保存 run；不切换 | 可用 |
| `/status` | 当前 ID、标题、创建时间、运行状态、模型、成功轮数、completed run 数/总耗时、usage 与保存/持久化状态 | 可用 |
| `/model` | 查看当前模型与入口获准显示的配置引用；只读 | 可用 |
| `/cancel`，别名 `/stop` | 固定当前 run 并请求取消；空闲返回 `no_active_run` | 可用 |
| `/clear` | TUI 清屏重绘，保留上下文、统计与历史 | 可用；仅 TUI |
| `/exit`，别名 `/quit` | 退出 TUI，沿用总期限内的取消与资源收尾 | 可用；仅 TUI |

公共解析规则如下：

- 忽略输入开头的 ASCII 空格与 Tab 后判断 `/`；普通消息保持原文本。只解析本次主动输入的顶层文本，不解析模型输出、工具结果、历史正文、引用或代码围栏中的命令。
- 命令名严格区分大小写，正式名称与别名来自同一目录；输入前缀仅供建议，`/res` 等不完整名称返回 `unknown_command`，不会执行候选首项。
- `//` 先转义为普通消息，移除一个 `/` 后不再解析；例如 `//tmp/a.txt` 发送 `/tmp/a.txt`，转义正文允许多行。
- 单 `/` 开头的指令必须为有效 UTF-8 单行文本，拒绝控制字符和 Unicode 行/段分隔符。参数只按 ASCII 空格/Tab 分隔，不运行 Shell、不解释引号、不展开环境变量。
- 页码为从 1 开始的正整数；非法、重复或多余参数返回 `invalid_arguments`。`/history` 的页码和 `--session` 可交换位置，同一参数只能出现一次。
- ID 为至少 8 位十六进制前缀，解析后统一小写；显示短 ID 不保证在每个可见集合中唯一。不可见或不存在均为 `session_not_found`，多个可见匹配为 `session_ambiguous`，须给更长 ID。
- 手工标题为 1–120 个 Unicode 字符，拒绝空白、控制字符及换行；标题可含普通空格。`/new` 可不带标题，`/rename` 必须带标题。无需对含空格的标题加 Shell 引号。

在线 `/demo` 是未知指令；offline 装配仅为既有单行 `/demo ...` 演示做显式转义，继续由脚本化 fake 模型处理。它不属于公共目录。

## 身份、工作区与权限

本地权限域为 `local`，与最终 `tools.workspace` 的规范绝对路径共同过滤历史；符号链接目录按真实路径识别，不同 worktree 或移动后的目录不会自动关联。

可信渠道的 `Scope` 包含 `channel + account_instance + peer + thread + sender`；必须由未来适配器在鉴权后提供，所有字段须完整且为有效 UTF-8。正文自称身份、标题或客户端给出的 session ID 均不授予权限。渠道入口拒绝本地形状的身份，服务固定在启动时配置的作用域。

先筛选同权限域、同工作区，再解析完整 ID 或前缀。即使工作目录相同，不同渠道、账号、对话、线程、发送者及本地入口也不能浏览或恢复彼此的历史。当前群聊形状按 sender 隔离只表示上下文隔离，不承诺平台回复私密。

当前仅用测试内的 fake gateway 验证上述契约；`internal/channel` 仍为渠道注册信息，不存在真实微信、飞书、QQ 适配器或 `plume gateway` 命令。未来适配器仍需实现真实鉴权、提及/按钮归一化与平台显示。

## 会话、标题与分页

会话 ID 为随机 32 位十六进制值。初始标题为 `New conversation`；首次普通输入取首个非空行、最多 60 个 Unicode 字符作为自动标题，不发起额外模型调用。手工命名后不再被普通输入覆盖。

默认未命名且无 run 的空会话只驻留当前服务的进程内存，避免每次打开退出产生磁盘空记录。`/new title` 或 `/rename title` 会立即保存元数据；首次普通输入写 run 起点时保存默认空会话。`/sessions` 和无参数 `/resume` 只列 store 已有元数据，即有 run 或已手工命名的会话；默认空会话不出现在目录。当前或已知 ID 的默认空会话可以在同一服务进程内按 ID 恢复，进程退出后不可恢复。

目录按最近 run 时间倒序，再按创建时间与 ID 稳定排序；重命名、浏览、预览不更新时间，不抢占 `-c` 的最近有 run 选择。目录显示 ID、标题、模型、run 数、完整成功轮数和可继续状态；模型引用不可用时仍可列出、只读查看，恢复返回 `resume_incompatible`。

`sessions.page_size` 同时控制目录和 run 分页，默认 20、有效范围 1–100。历史第一页选择最近一页 run，页内按发生顺序显示；包含 failed/cancelled/interrupted 等展示记录及已保存 running 起点，未保存的实时分片不会凭空出现。合法但超过总页数的查询返回空页。

历史展示与模型恢复是两条读取路径。分页只供人查看；恢复完整成功 turns、调用快照和展示 runs 时仍受 G4a.1 的字节/记录/JSON 展开上限约束，超限明确拒绝，不以分页或截断凑出可发送上下文。整库损坏时不保证只读历史仍可用。

## 新建与恢复模型

裸 `plume` / `plume chat` 始终开新会话；`-c/--continue` 只找当前工作区最近有 run 的本地会话。找不到时提示后新建，引用不兼容、损坏或占用则明确拒绝；offline 与 `-c` 互斥，持久历史关闭时 `-c` 报错。

`/new` 和 Ctrl+N 使用**本次实际启动选定的模型**，具体为：

- 裸启动使用本次配置快照的 `default_model`。
- 显式 `plume chat --model <ref>` 使用该引用。
- `-c` 成功恢复后使用启动时由历史恢复选定的引用。

后续 `/resume` 切换到其他历史不会改变这个新建模型基准。`/resume` 可选当前启动配置快照中的其他兼容引用，按目标历史 `model_ref` 重建运行时；这是重新打开原会话，不是把同一历史迁移到另一模型。`chat -c --model <ref>` 仍必须与所选历史引用兼容。

兼容匹配优先按 ConfigID 并核对 provider、协议、模型与规范 endpoint 指纹；同 ID 已变更则拒绝。仅当旧 ID 不存在时，才允许查找完全同指纹的重命名配置。凭据从当前安全存储解析，不从历史恢复；不联网 probe，不在 `/resume` 时重读整个配置文件。

每次恢复或新建得到新的工具运行时，使用本次启动配置快照的工具许可、预算与 reasoning 偏好。历史 `read` 正文不能恢复先读后改的证明，后续 edit/write 须重新实际 read。每个新 run 按当前基础规则、当次 soul.md 快照和工作区构造唯一 system，旧 system 不作为恢复来源；详情见 [工具契约](agent/tools.md) 与 [人格契约](agent/soul.md)。

恢复只把完整成功 turns 加入下一次模型请求，失败/取消/中断只显示；不自动发送旧输入、不重放工具。usage 按 call ID 恢复去重统计，未知保持 unknown/partial。保留原会话创建时间，状态栏 session 从本次打开重新计时；ctx 为最近一次实际 PromptTokens，不是累计量或下一次估算。

切换先完整校验和准备新运行时，再提交绑定与收据，确认后才更新内存和 TUI。失败保留原会话、转录、统计、草稿与面板，关闭准备的新资源。成功后清空本地草稿及 Up/Down 草稿历史，重建净化转录和统计，开屏不重新出现。

## 收据、取消与保存边界

`RequestID` 是入口提供的消息关联，本地未提供时生成独立关联。收据键包含权限域、工作区与 RequestID，内容指纹包含原输入和入口类型；同关联、同内容返回首次结构化结果并标记 `Replayed`，不同内容返回 `request_conflict`。

SQLite `user_version=2` 前向迁移增加 `sessions.scope_key/title_manual`、`bindings` 和 `command_receipts`；旧 v1 会话归属 `local`，旧数据保留。命名空会话创建、绑定、重命名与命令收据同事务提交。内存后端执行同一验证和原子发布契约；config schema 仍为 v1，无新增外部依赖。

重复 `/new`、`/resume`、`/rename` 只回首次结果，不再创建或切换，也不会把旧标题覆盖后来更改。收据重放去掉终端动作和切换快照；只读操作沿用首次快照。收据不进入模型历史。

`/cancel` 在与 run 准入共同的锁内固定首次目标 run ID；先保存收据，再按该 ID 请求取消。空闲时保存无目标结果。若收据已提交但提交核查失败、取消信号尚未送出，重投仅在收据固定 ID 仍是当前活动 run 时补发信号；无目标或旧 run 收据不能影响后来任务。`cancel_requested` 只表示已请求取消，直到旧 run 终态才可新建、恢复或重命名。

事务返回错误后按原关联核查收据：确认已提交则同步第一次结果；确认未提交则保持原会话并返回存储错误；查询也失败则标记 `history_uncertain`、冻结新 run 与切换，须重开校验，不重跑模型/工具来补历史。run 的三段式落盘、总退出期限与整库生命周期锁沿用 [G4a.1](../reviews/G4a.1.md)。

fake gateway 仅验证命令动作和回执重试复用，不承诺真实平台 exactly-once。持久 inbox/outbox、平台回执投递、崩溃窗口、游标推进、`delivery_unknown` 与跨进程会话所有权仍属 G2b。

## TUI 建议与只读面板

输入 `/` 或小写指令前缀时显示内置候选，最多占六行；含参数、多行或 `//` 转义正文不补全。Up/Down 选择候选，Tab 只替换输入，Enter 执行实际文本。Esc 关闭建议且保留草稿，编辑后可重新显示。候选与 `/help` 共用目录，通过 `CompletionProvider` 留出候选来源接口；没有 MCP/skill 加载器、配置或发现逻辑。

`/resume` 与 `/sessions` 目录面板使用 Up/Down 选择、Tab 预览、Enter 恢复、PgUp/PgDn 翻页；预览中 Tab 返回目录，Ctrl+O 展开/折叠保存的 Thought 与工具摘要。独立 `/history` 面板同样分页，Up/Down 在正文内滚动。标题和正文每次渲染都净化控制序列并按当前窗口换行，长中文标题不会撑开列表行。

Esc 优先关闭面板并保留当前会话与原草稿，再次按 Esc 才沿用直接取消 run 的语义；Ctrl+C 在 running 时始终优先请求取消，不被建议或面板拦截。Ctrl+N 复用 `/new` 的应用层操作。命令异步回执以序号保护，run 事件携带 session ID 和 run ID，迟到消息不能污染新会话。

TUI 管理面板和通知不写入对话转录；一次输入正在异步处理时连按 Enter 被拒绝，避免重复请求。成功回执只消费仍等于本次原输入的草稿，处理期间新编辑的草稿保留；会话切换成功则按切换契约清空草稿。

## 远端显示与剩余范围

可信渠道的 `/history` 清除 Thought 和工具详情，每个 run 的输入/回复裁为最多 2000 个 Unicode 字符并带省略标记；执行诊断错误替换为固定失败说明，避免外发人格/凭据文件路径或服务地址。管理状态和模型结果不包含本机工作目录、endpoint、凭据引用或完整配置；失败回执使用固定状态码说明。正文自身含有的路径或其他敏感内容不会被语义猜测、改写或承诺自动脱敏，未来平台仍要净化与按发送长度渲染。

`/clear`、`/exit`、`/quit` 在可信渠道返回 `unsupported_entrance`，不退出服务。真实渠道身份和模型可见集合必须由适配器限制；同一处理器的存在不代替平台鉴权。

当前不提供 `/model <ref>`、`/think`、`/compact`、`/memory`、`/skill`、`/mcp`、删除/导出历史、自动保留期、自动压缩或长期记忆。正式验证与平台人工体验未完成的项目保持 N/A，不能从本地 fake/fixture 推导真实模型质量或供应商延迟。
