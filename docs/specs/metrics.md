# 指标与比较协议

> 2026-10-09 从第一阶段计划 §7 抽出，作为第一/第二阶段共用的协议；阶段计划只保留对本文的引用。

## 1. 固定指标字典

| 指标 | 定义 | 趋势 |
| --- | --- | --- |
| 任务成功率 | 满足全部检查点的 run / 所有计划执行的 run；错误/超时计失败 | 高 |
| 工具选择/参数正确率 | 符合允许工具与参数的任务 / 适用任务；正确不调用也计入 | 高 |
| TUI 首文本延迟（首答案） | 提交输入至首个可见答案写入渲染帧；状态提示和思考预览均不算回答 | 低 |
| 模型首文本延迟（首答案） | 模型调用开始至首个有效答案增量；不包含请求前准备、思考和 usage，不等于 token 级真值 | 低 |
| 模型首思考延迟 | 模型调用开始至首个有效思考增量；无思考为 N/A，不能替代首答案指标 | 单列 |
| 准备耗时 | 接受输入至第一次模型调用开始；前置失败另报实际终止耗时 | 单列 |
| TUI 完成延迟 p50/p95 | 提交至最后内容和终态完成渲染；不等同于用户阅读完成 | 低 |
| Agent 延迟 p50/p95 | run 开始至最终答案完成，不含 UI 绘制或未来渠道发送 | 低 |
| 取消响应耗时 | 接受取消至请求/工具退出、body 关闭且产生终态 | 低 |
| Token / 模型调用数 | 每任务及完整会话的 usage/调用数，包含失败尝试与摘要；未知单列 | 低，需质量约束 |
| 费用/任务、费用/成功任务 | 总费用除以任务数/成功数，注明币种、价格日期、缓存计价 | 低 |
| 解析正确率 / 本地开销 | 固定 fixture 的消息/事件一致性；ns/op、B/op、allocs/op | 正确率高、开销低 |
| 吞吐 | 固定并发、超时下应用层成功任务/时间，不用 UI 刷新率代替 | 高 |
| 重复执行率 | 同一逻辑任务非预期重复执行的比例；后续重复发送独立统计 | 低 |
| Trace 完整率 | 节点与关联检查通过 run / 所有 run，崩溃未闭合计不完整 | 高 |
| Trace 开销 | 相同负载下开/关采集的延迟、吞吐、CPU、内存、存储增量 | 低 |
| 首次配置指标 | 成功率、失败原因、恢复/probe 耗时；人工输入与系统时间分开 | 成功率高、耗时低 |
| 后续能力指标 | 记忆召回/错误率、渠道收发成功率、扫码/恢复/发送耗时 | 未实现标 N/A |

延迟报告同时列失败率、超时数和所有任务的终止耗时；仅成功任务的分位数注明分母，不能靠快速失败制造"更快"。终端测量注明 OS、终端、窗口大小与渲染策略。工具型无文本事件的首文本指标记 N/A。

**二进制体积与依赖增量不作为指标**：它不随执行链路变化，也不回答"哪一步变慢了"。依赖版本锁定与兼容性记录见 `../AGENTS.md` 依赖表；性能一律以本文件的延迟与成功率指标为准。

## 2. 数据与实验协议

1. G1b.1 建立 12 个工程回归种子；流式/TUI/工具 fixture 分开版本化。G3 起逐步扩充核心 100 例：对话 15、工具 30、记忆 20、技能 15、可靠性/异常 20；未实现类别不运行、不计成功，公开适用 case ID。
2. 核心集按类别拆开发集 60/保留集 40，同源变体同组；只用开发集调参。看过并据此修改后的保留集不再称未见测试集。
3. 确定性任务按实际参数/结果评分；开放回答使用固定人工 rubric。若引入模型裁判，锁定模型/prompt，抽查至少 20%，费用单列。
4. baseline/candidate 配对、交错运行，相同 case、模型版本、参数、工具状态、并发、超时与环境；真实模型默认每例 3 次，联网实验逐项显式发起。
5. manifest 保存机器/OS/Go/openai-go/TUI 依赖版本、commit 或工作区内容哈希、配置与数据集哈希、provider/内部协议/模型 ID、日期、并发、随机种子（若支持）、缓存状态、逐例结果和 trace 引用。温度 0 不保证确定性。
6. 延迟注明算法与样本量；p95 优化结论原则上每配置至少 200 次可比请求。置信区间按 case 分组做配对 bootstrap，不把同题重复当独立题。
7. 假模型只测本地运行时/协议/界面，不推断真实模型质量；真实 HTTP、模型推理和 UI 开销分开归因。移除框架不自动产生性能收益。
8. 数据缺失记 N/A/unknown，不能当 0。存在未知 usage/价格时费用标为部分已知或 unknown，不将已知小计当完整费用；零成功任务的费用/成功任务为 N/A。

## 3. 每次改造的固定报告

`eval/reports/<experiment-id>/` 保存 `manifest.json`、`baseline.jsonl`、`candidate.jsonl`、`comparison.md`，公开数据脱敏。

| 指标 | 改前 | 改后 | 绝对差 | 相对变化 | 样本/区间 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 全部适用指标 | 实测 | 实测 | 新−旧 | (新−旧)/旧 | 实测统计 | 改善/退步/不确定 |

基线为 0 时相对变化记 N/A；比例绝对差用百分点。80% → 84% 是 +4 个百分点、相对 +5%；10s → 8s 是 −2s/−20%。这些是算术示例，不是测量结果。

未来比较入口 `rtk go run ./cmd/eval compare --baseline <目录> --candidate <目录>` 须校验数据集与环境可比性；当前并不存在此命令。默认采纳门槛：主指标达到事先假设，成功率配对差 95% 区间下界不低于 −3 个百分点；其他非目标质量点估计下降不超过 3 个百分点；p95 和每成功任务费用恶化不超过 10%；隔离、越权、重复执行无新增失败。样本不足记"不确定"，取舍提交用户审核。
