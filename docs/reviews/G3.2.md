## 4. 局限与审核项

- 默认文件发布依赖文件系统支持硬链接；目录 fsync 与既有配置写入一致采用尽力同步，不承诺断电事务。读取也不是与外部写入者隔离的事务，建议编辑完成后再发送。
- Unix 非阻塞打开后核对实际类型，避免替换成 FIFO 阻塞；非 Unix 使用标准打开，Windows 尚未实测。
- 不支持多人格、项目内递归发现或运行中配置热切换；文件正文在下一 run 更新，配置修改需重启聊天。
- 本单元未测试真实供应商对人格的遵循程度，没有 token 估算/压缩/记忆。路线图仅更新数据并通过静态解析，本地 file URL 的浏览器视觉验收受既有策略限制未进行。
