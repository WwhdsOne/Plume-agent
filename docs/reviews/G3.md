## 实际改动

- 新增 internal/tools 不可变许可注册表、calculate 与 current_time；声明和执行同源、排序稳定，参数严格校验，除零/溢出及未知工具返回结构化错误。
- Agent 统一构造基础规则、完整历史和本 run 轨迹；Generate/Stream 使用同一模型→串行工具→模型循环。分片参数完成、finish/DONE 证据齐备后才校验执行；重复 ID、损坏协议、截断、预算耗尽和取消明确终止，不自动重试。
- OpenAI SDK 编码结构化 tools；DeepSeek tools 请求回传全部 assistant reasoning_content。标准兼容端点不发送供应商扩展；本地 HTTP fixture 覆盖两种传输及分片回传。
- app 原子提交完整成功消息组，失败/取消隔离；历史工具切片深拷贝。模型步骤有独立 ID，usage 尾帧/终态替换同一步统计；ctx 最近输入、cache session/last_call 设置继续适用。
- TUI 用亮青 `◇` 行原位更新工具状态与摘要；每次模型步骤独立 Thought/答案，显示执行顺序。继续净化终端控制序列。工具后的缓存等待保留上一调用快照，未把 unknown 当零写入统计。
- 整体 deadline 从接受输入开始，并传入有界事件桥；修复事件队列满及 started 发送等待绕过 deadline 的边界。模型/工具超时均尊重整体期限。
- 脱敏 trace 增加 prompt 摘要、工具开始/校验/终态、父 model ID；原始参数、结果、prompt 与思考不落盘。未知名称只记录 unknown。
- 离线增加明确 `/demo` 协议场景；普通离线输入保持固定回复，不读真实配置。新增 30 例 tools.v1 与 G3 PTY 脚本；无新外部依赖、配置 schema 或 setup 问题。
