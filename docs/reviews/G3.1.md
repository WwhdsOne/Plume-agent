# G3.1 开发工具与可配置预算审核

原 G3 的计算器和时间工具无法完成开发任务，8 次模型/工具调用也容易过早结束。按用户授权，在线默认工具改为 `read`、`grep`、`glob`、`edit`、`write`、`bash`；循环次数与整轮时长默认无限，仍保留每步、字节和超时约束。已在原目录实现并安装。用户于 2026-10-09 明确“审核通过，提交并且推送吧 G3.1”，通过范围包含基础 G3 循环及追加的状态栏默认隐藏 ctx。初版 G3 记录保留为历史交付快照，对应范围与默认值以本记录及[工具契约](../specs/agent/tools.md)为准；后续单元不自动推进。

## 实现与配置

- `internal/tools` 实现文件分页读取、搜索、定位、精确替换、原子写入及本机命令；注册表统一声明、校验和执行。计算器/时间仍可显式启用。
- `internal/config` 增加 `agent.budget` 和 `tools`，schema v1 兼容扩展，无新增外部依赖。默认值实际写入文件；旧文件原子补齐，保留未知字段、用户指定的 0 和空工具列表。setup 不增加问题且保留已有设置。
- `internal/agent`、`internal/app` 消除隐藏的 8 次限制和零时长立即超时；保留有限预算预检、取消、工具结果按 ID 回填及成功历史原子提交。
- CLI 将配置转换为真实运行选项；基础提示词版本 `plume-workspace-v1` 带实际工作目录、先读后改和副作用约定。TUI/trace 只展示固定摘要、数量与错误码，文件正文和命令不写 trace。
- 离线 `/demo workspace` 提供六工具真实闭环，仍不读用户配置；普通离线输入仍为固定回复，不代表真实模型会自主选择工具。

完整默认值见[配置契约](../specs/config.md)。审核期落盘样例原位于 `evidence/G3.1/config/default-config.json`，其中 `custom_root: preserved` 验证未知字段保留；样例随审核通过删除，迁移与保留行为仍由配置测试覆盖。

## 保留局限

文件工具通过 os.Root 限制路径和链接；`bash` 是启动用户权限下的本机 shell，可访问工作区之外，未提供沙箱。Unix 取消清理同一进程组，独立脱离的进程组不保证清理；非 Unix 仅终止直接子进程，Windows 未实测。失败/取消不回滚已写文件，不自动重试；prompt 要求遵守用户对破坏、发布、推送及发消息的授权，当前没有自动弹出的工具权限审批界面。

搜索跳过固定目录，尚不解析 .gitignore；glob 不支持花括号展开。超长单行 read 只返回有界前缀并推进下一行，尚无字节续页。新文件原子 Link 防止并发创建覆盖，现有文件摘要检查到 Rename 之间仍有外部修改竞争窗口；同步失败返回 applied 标记。无限次数仍可能达到 8 MiB 请求上限，当前不会自动压缩上下文。
